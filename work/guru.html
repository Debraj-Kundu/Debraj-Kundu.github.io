01 / THE PROBLEM

Screening interviews are repetitive and hard to keep consistent. Guru lets a recruiter set up a job once (questions, scoring criteria and a company knowledge base) and then sends candidates an invite link to an audio-only interview run by a voice agent.

Afterwards every answer is scored per criterion, with evidence that links back to the exact transcript turn. Scores are advisory: a human always makes the decision.

02 / THE ENGINEERING

Three parts: a Next.js web app for recruiters and candidates, a FastAPI service that owns all state in PostgreSQL, and a LiveKit Agents worker that runs one process per interview. The web app never holds LiveKit keys; the API issues tokens, and the agent talks back through an internal API protected by a service token.

Knowledge-base files go browser → S3 directly via presigned URLs, then a background ingest parses, de-duplicates by sha256 and embeds them into Qdrant (dense + BM25), filtered by org and job. Plan generation, ingestion and scoring all run as background work that resumes after an API restart.

03 / THE RESULT

A complete, testable system: recruiter dashboard, candidate interview page, a voice agent with consent, follow-ups and closing Q&A, and evidence-linked scoring, with architecture, flow, state and schema diagrams documented in the repo.

DETAILS THAT MATTER
  • Secure ingestion: 20 MB / 50-source limits, SSRF checks on every redirect hop, robots.txt respected, 5 MB / 10 s fetch caps.
  • Bounded concurrency: a semaphore limits ingests; process-pool parsing keeps the API responsive.
  • Consistency: editing a job bumps its version and marks the saved plan stale; plan generation is single-flight (409 on duplicates).
  • Session state machine: created → active → completed / declined, one attempt per link, a 120 s rejoin window, silence check-ins and a hard time cap.
  • LLM resilience: OpenRouter for text calls with Gemini as fallback; scoring left mid-flight is resumed on startup.
  • Privacy: Qdrant never holds candidate data; declined consent stores nothing.
