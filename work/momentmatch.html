01 / THE PROBLEM

Large photo libraries are hard to search. MomentMatch lets people describe a moment in plain words and finds matching photos across the whole library.

02 / THE ENGINEERING

Photos are embedded with InsightFace and CLIP models and stored in Qdrant for prompt-driven semantic search.

Processing runs through an idempotent asynchronous pipeline with robust retries and failure recovery, so re-running a job never duplicates work. Redis handles caching and background jobs.

03 / THE RESULT

99.99% processing reliability for user data, and 40% better API responsiveness and scalability under high-throughput workloads.

DETAILS THAT MATTER
  • Reliability: idempotent jobs with retries and recovery.
  • Performance: Redis caching in front of hot reads.
  • Polyglot services: FastAPI for ML work, Spring Boot for core APIs, Next.js for the UI.
